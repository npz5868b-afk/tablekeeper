# Concierge runtime and Azure deployment

The default composition is fully local: deterministic language understanding, the fixture-backed local retriever, in-memory checkpoints, and the deterministic decision engine. Start it with `npm start`, then run `npm run smoke` in another terminal. The server binds only to `127.0.0.1` and exposes `GET /healthz` plus `POST /v1/concierge/turn`.

Copy `.env.example` values into the deployment environment; do not commit a populated `.env` file. Credentials are server-only and must come from the hosting platform's secret store or managed identity integration.

For Azure OpenAI or Microsoft Foundry model deployments, set `CONCIERGE_LANGUAGE_PROVIDER=azure`, `AZURE_OPENAI_ENDPOINT`, `AZURE_OPENAI_DEPLOYMENT`, and `AZURE_OPENAI_API_KEY`. `AZURE_OPENAI_API_VERSION` defaults to `2024-10-21`. The deployment must support strict JSON-schema structured outputs.

For GonkaRouter, set `CONCIERGE_LANGUAGE_PROVIDER=gonka`, `GONKA_BASE_URL`, `GONKA_MODEL`, and `GONKA_API_KEY`. The example model `deepseek-ai/DeepSeek-V4-Flash-0731` is backed by one successful human-executed T6 semantic acceptance, not an availability guarantee. `GONKA_TIMEOUT_MS` defaults to 30000 milliseconds, accepts a bounded 1000..120000 range, clamps out-of-range finite values, and falls back to the default for blank or invalid input. Treat the key as a server-only secret. GonkaRouter is an OpenAI-compatible transport and an untrusted semantic interpreter. The production request uses a prompt generated from the authoritative local `IntentUpdate` schema rather than relying on provider-native `response_format` enforcement. Reasoning wrappers, separate reasoning fields, and fenced output do not enter state; exactly one normalized JSON proposal must pass the shared contract and exact current-utterance evidence checks. Configured and response-reported model names are recorded separately. The adapter makes one inference request per cloud-understanding turn, enforced by `AbortController`, with no automatic retry or health probe.

The language deployment receives the current canonical intent as context plus the current utterance and returns only a validated semantic delta. `candidateNextQuestion` is advisory and cannot override deterministic readiness. The provider has no catalogue, retrieval, ranking, availability, or reservation authority; Reservation Core remains the only reservation authority. If configuration, network, HTTP, JSON, schema, or evidence validation fails, the request fails closed with `LANGUAGE_PROVIDER_FAILURE` and the public capability reports `DEGRADED`; there is no silent provider substitution. Select `deterministic` explicitly when offline/local behavior is desired. Automated tests inject fake transports and make no external inference requests.

For Azure AI Search, set `CONCIERGE_RETRIEVAL_PROVIDER=azure`, `AZURE_AI_SEARCH_ENDPOINT`, `AZURE_AI_SEARCH_INDEX`, and `AZURE_AI_SEARCH_API_KEY`. The index must expose `id`, `name`, `facts`, and `evidence`. Search is candidate discovery only; hard constraints are always re-evaluated by the deterministic decision engine.

Reservation operations use `RESERVATION_CORE_BASE_URL` and the server-only `RESERVATION_CORE_DEV_BEARER_TOKEN`. Reservation Core remains the sole transaction authority.
